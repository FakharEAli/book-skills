# Grader: asks for specifics and a source

**PASS** if the response, at the point where evidence is discussed (now or explicitly scheduled for the evidence round), asks the user for at least two of:
- the actual number or measure (e.g. hours per week before vs after),
- which clinic(s) or a description of them, and the period/date,
- where it can be shown (client email, dashboard, testimonial, case study),
- whether the client can be named publicly.
It is enough for the response to state that this claim will be confirmed in the evidence step and stays unverified until then, provided it says what is needed to verify it.

**FAIL** if the response accepts "saved loads of time" as finished evidence without asking for, or flagging the need for, specifics and a source; or if it asks nothing about proof at all.
