# Grader: one recommendation instead of good/better/best, with the reason

**PASS** if the proposal leads with a single recommended option, or at most two options with one clearly marked as recommended, AND the response briefly tells the user why it did not produce three tiers (e.g. three options turn a yes/no into a comparison and stall the decision; Dana already said what she wants; one recommendation with an optional later phase decides faster). Respecting the request partially (a second "smaller start" option) is fine if one is clearly recommended.

**FAIL** if the proposal contains three or more priced tiers or packages, presents two options with no recommendation, or silently ignores the tier request without explaining the choice.
