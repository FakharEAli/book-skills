# Grader: ROI math shown, built only from the given numbers

**PASS** if the proposal shows the impact calculation with its inputs and the return against the price, using only figures in the prompt. Reference values (accept equivalent correct arithmetic and stated conservative assumptions):
- Missed new jobs: 25 calls/week × 40% new × 50% booked × £420 × 50 weeks = £105,000/year
- Admin time: 6 h × £18 × 50 weeks = £5,400/year
- First-year price: £6,500 + 12 × £350 = £10,700
- ROI ≈ £110,400 ÷ £10,700 ≈ 10.3× (or ≈ 9.8× on missed calls alone); payback ≈ 1.2 months

The formula or inputs must be visible, not just a final number.

**FAIL** if there is no ROI or payback math, the arithmetic is materially wrong (off by more than 10%), or the response introduces numbers not in the prompt as if they were Brightline's (industry benchmarks, "typical clients see…") without labelling them as assumptions.
