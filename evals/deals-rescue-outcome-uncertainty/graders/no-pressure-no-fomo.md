# Grader: no pressure, no FOMO, no "just checking in"

Dixon & McKenna show that adding urgency or fear of missing out to an indecisive buyer deepens the indecision, because the dominant fear is messing up. Ravi's last email was a "just checking in" that went unanswered.

**PASS** if every drafted message (primary, alternative channel and any variant):
- Contains none of: "just checking in", "checking in", "circling back", "touching base", "any update", "bumping this", "following up on my last email".
- Contains no artificial urgency or scarcity: no deadline for the price, no "limited slots", "before winter fills up my diary", "price goes up", "offer ends", "last chance", and no discount.
- Does not use loss-framed pressure as the lever (e.g. "every week you wait costs you £2,500"). Briefly echoing Dana's own words about the cost is allowed only if it is not the main push and not inflated.

**FAIL** if any draft contains any phrase or tactic above, or if the response recommends creating urgency to get Dana to decide.
