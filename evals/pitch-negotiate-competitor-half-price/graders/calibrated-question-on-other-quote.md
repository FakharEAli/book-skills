# Grader: calibrated question about what the other quote covers

**PASS** if the script includes at least one open "What…" or "How…" question that gets Priya to describe the competing quote's scope or terms before the user argues value. Examples: "What does their quote include?", "How are they handling two-way rebooking with Cliniko?", "What happens after go-live with their option, who maintains it?" A label first ("It sounds like you want to be sure you're not paying twice for the same thing") is a plus but not required.

**FAIL** if there is no question about the other quote, if the only questions are closed yes/no ("Is it the same scope?") or start with "Why" ("Why are they cheaper?"), or if the response assumes the competitor's scope is worse without asking.
