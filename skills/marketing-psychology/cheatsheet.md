# Cheatsheet: decision rules, trees, thresholds, tells

## 1. Decision rules (When X → do Y, because Z)
- **Prospect hesitates** → diagnose the REDUCE barrier before replying (07), because more evidence for a reactance problem makes it worse.
- **Opening a call or page** → make their problem focal with a question or number before anything about you (04), because focal = important.
- **Quoting a price** → put a reference point in the same sentence (02, 01), because value is relative.
- **Quoting a saving** → over 100: pounds; under 100: percent (06 Rule of 100).
- **Writing a claim** → ask "could a camera film this?" (05); if not, rewrite.
- **Showing proof** → same size + same sector, or it won't translate (07, 01).
- **Tempted to say "most firms haven't..."** → don't (01, 02 negative social proof).
- **Competitor is cheaper** → hold price, add a costly signal (guarantee, named engineer) (08), because cutting price signals doubt (03).
- **Prospect says "not now"** → surface the cost of inaction in £ per month, then shrink the ask to one workflow (07).
- **Owner anxious, asking "just tell me"** → decisive, dominant messenger (09); **owner exploring** → warm, menu of options (07, 09).
- **About to admit a flaw** → only after competence is shown (09, 02 pratfall).
- **Designing content** → one core, one surprising line, one trigger moment (05, 06).
- **Rebrand urge** → don't; keep distinctive assets fixed (10).
- **Choosing who to reach** → whole serviceable segment, continuously (10), not ideal-customer only.
- **Automating a human step** → list its hidden functions first (08 doorman).
- **Unsure which bias applies** → run a 50/50 test for a week (02), because claimed data lies.

## 2. Decision trees

**Hesitation diagnosis (07 REDUCE)**
- Pushing back on *you* / arguing → **Reactance** → menu, ask-don't-tell, restate their view.
- "Current way works fine" → **Endowment** → cost of inaction in £, cumulative; look for a "ships burning" event.
- "Too big a change / not for us" → **Distance** → shrink to first workflow; switch field to a goal they hold.
- "Not sure it'll work here" → **Uncertainty** → pilot, fixed fee, reversible, old process intact.
- "Who else like us?" → **Corroborating Evidence** → 3 similar, independent proofs within a week.

**Which implicit goal is the owner buying? (03)**
- Talks about things breaking, being missed, dependence on one person → **Security / Discipline** → signals: monitoring, runbooks, named engineer, SLA.
- Talks about stepping back, freeing time → **Autonomy** → signals: "runs without you", hand-over docs.
- Talks about edge, being first, "AI" → **Excitement / Adventure** → signals: novelty, demos; rare among operators, confirm before leaning on it.

**Which messenger traits for this touchpoint? (09)**
- Cold / first contact → Competence + Trustworthiness.
- Buyer frozen, uncertain → add Dominance (decisive recommendation).
- Long-term account → Warmth + Trustworthiness; vulnerability only after wins.

**Which lever first? (order across books)**
1. Attention (04) → 2. Barrier removal (07) → 3. Value frame (03) → 4. Proof (05, 07, 09) → 5. Push levers: scarcity, commitment (01).

## 3. Trade-off matrices

| Choice | Prefer when | Avoid when |
|---|---|---|
| Hard messenger (status, dominance) vs soft (warmth, vulnerability) (09) | uncertain, competitive, buyer asking for direction | cooperative, relational, buyer exploring |
| Differentiation vs distinctiveness (10 vs 03/07) | proposal/sales conversation → differentiation (mechanism, fit) | brand/content layer → distinctiveness (fixed assets) |
| Push levers (01) vs barrier removal (07) | barriers already down, decision imminent | any sign of reactance or uncertainty |
| Narrow targeting vs broad reach (10) | the proposal and outreach copy | the content system and brand presence |
| Lower price vs lower pain (03) | almost never price first | — reduce effort, risk, uncertainty first |

## 4. Thresholds and defaults the authors commit to
- Rule of 100 for % vs absolute (06).
- Pareto is ~60/20, not 80/20; light buyers are the majority (10).
- Losses weigh roughly 2× gains; frame inaction as loss (07).
- One strong source for weak resistance; several concentrated sources for strong (07).
- Six implicit goals: security, enjoyment, excitement, adventure, autonomy, discipline (03).
- Eight messenger traits: 4 hard (socio-economic position, competence, dominance, attractiveness), 4 soft (warmth, vulnerability, trustworthiness, charisma) (09).
- Seven principles (01): reciprocity, commitment/consistency, social proof, liking, authority, scarcity, unity.
- Default offer structure: 3 tiers, premium shown first (01 contrast), one monthly figure (02).
- Default proof: 1 named Challenge story (05) + 3 similar short proofs (07) + 1 Sinatra credential (05).

## 5. Tells and smells
- Copy full of "AI-powered / seamless / cutting-edge" → curse of knowledge + semantic stretch (05); rewrite concretely.
- Homepage leads with your story or your stack → attention misdirected (04); problem-first.
- Prospect asks lots of "what if" questions → **Uncertainty** barrier (07), not price.
- Prospect argues with every point → **Reactance** (07); stop presenting, start asking.
- Prospect says "we've always done it this way" → **Endowment** (07).
- Proposal itemised by hour → pain of payment maximised (02).
- Logo wall of enterprises for an SME buyer → translation problem (07).
- Engagement high, inbound low → mental availability not attached to buying situations (10, 06).
- You changed the brand look this year → recognition reset (10).
- Client quietly reverting an automation → doorman fallacy; a hidden human function was lost (08).
- You're explaining why the price is fair → the frame is wrong (03); re-anchor instead of defending.
- You said "most SMEs haven't adopted..." → negative social proof (01, 02).
